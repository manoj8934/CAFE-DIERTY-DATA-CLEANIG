# CAFE-DIRTY-DATA-CLEANIG
Data cleaning and Quality checks on a cafe dirty dataset using python and pandas
Project Overview

This project focuses on cleaning and preparing a cafe dataset for reliable data analysis. It demonstrates practical data-cleaning techniques using Python and Pandas.

Objectives

- Identify and handle missing values.
- Detect and remove duplicate records where appropriate.
- Check and correct data types.
- Identify invalid or inconsistent values.
- Prepare a clean dataset for further analysis.

Tools and Technologies

- Python — data cleaning and processing
- Pandas — data manipulation and quality checks
- NumPy — numerical operations
- Jupyter Notebook or Python script — documenting and executing the cleaning workflow

Data Cleaning Process

1. Load the original cafe dataset.
2. Inspect the dataset structure and data types.
3. Check for missing values.
4. Identify duplicate records.
5. Review inconsistent or invalid values.
6. Correct data types where necessary.
7. Validate the cleaned dataset.
8. Export the cleaned data to a CSV file.

Project Files

- "dirty_cafe.csv" — original dataset, if included
- "cleaned_cafe.csv" — cleaned dataset, if saved
- "cafe_data_cleaning.py" — Python cleaning workflow

Results

The project is intended to improve data quality by addressing missing values, duplicates, inconsistent values, and data-type issues where present.

Actual cleaning results and before-and-after record counts will be documented after validation.

Skills Demonstrated

- Data inspection and profiling
- Missing-value handling
- Duplicate detection
- Data type conversion
- Data validation
- Exporting cleaned data to CSV
- Python and Pandas

Conclusion

This project demonstrates a practical approach to preparing raw data for analysis. Clean, consistent, and validated data helps improve the reliability of subsequent reporting and business insights.
